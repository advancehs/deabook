# 渲染说明（HTML 与 PDF 生成）

本书是一个 **Quarto Book** 项目，源文件为各章 Markdown（`01_绪论.md` … `13_…md` 与 `附录_…md`），由根目录的 `_quarto.yml` 统一配置。渲染后产物输出到 `_book/` 目录。

## 环境要求

| 组件 | 用途 | 说明 |
|------|------|------|
| Quarto ≥ 1.10 | 渲染引擎 | 本机路径 `C:\Program Files\Quarto\bin\quarto.exe` |
| TinyTeX（含 ctex） | PDF 排版 | 本机路径 `C:\Users\kerry\AppData\Roaming\TinyTeX\bin\windows\`，需含 `ctex.sty` 以支持中文 |
| 浏览器 / 阅读器 | 查看产物 | HTML 用浏览器，PDF 用阅读器 |

> HTML 渲染不需要 LaTeX；**只有 PDF 渲染才依赖 TinyTeX + ctex**。

## 渲染命令

在 `deabook文档` 目录下执行：

```bash
# 渲染为 HTML
quarto render . --to html

# 渲染为 PDF
quarto render . --to pdf

# 渲染所有在 _quarto.yml 中配置的格式（html + pdf）
quarto render .

# 只渲染某一个章节（调试用，输出到该章节同级或 _book）
quarto render 03_数据包络分析的经典模型.md
```

> 若 `quarto` 不在 PATH，用完整路径调用：
> `"C:\Program Files\Quarto\bin\quarto.exe" render . --to html`

## 输出位置

| 格式 | 产物 |
|------|------|
| HTML | `_book/index.html`（入口）及各章 `_book/<章节名>.html` |
| PDF | `_book/资源环境绩效评估方法：DEA模型与Python应用.pdf`（以书名命名） |

渲染会顺带生成 `.quarto/` 缓存目录，可安全删除（下次渲染会自动重建）。

## 关键配置（`_quarto.yml`）

```yaml
project:
  type: book

book:
  chapters: [index.md, 01_…md, …, 13_…md]
  appendices: [附录_…md]

crossref:
  chapters: true          # 图表与公式按“章.序号”编号（如公式 3.1）

format:
  html:
    theme: cosmo
    number-sections: false
  pdf:
    documentclass: book
    pdf-engine: lualatex   # 中文 PDF 用 lualatex
    include-in-header:
      text: |
        \usepackage{ctex}   # 中文支持
```

## 公式编号与交叉引用约定

- **编号**：公式用 `$$ … $$ {#eq-3-1}` 形式，Quarto 按“章.序号”自动编号（如 `(3.1)`）。
- **引用**：正文用 `([-@eq-3-1])` 引用，渲染为裸数字 `(3.1)`（`[-@…]` 去掉 “Equation” 前缀）。
- **子公式**：原 `7.22a`/`7.22b` 已位置化重编号为 `7.23`/`7.24`，后续公式顺延，引用已同步。
- **首页**：`index.md` 标题须带 `{.unnumbered}`，否则 `index.md` 会被计为第 1 章、导致全书公式编号整体 +1。

## 章节编号与交叉引用约定

- **编号**：各级标题带 `{#sec-…}` 自动编号，需 `number-sections: true`（HTML/PDF 均已开启）。章 H1 为 `{#sec-3}`，节 H2 为 `{#sec-3-1}`，小节 H3 为 `{#sec-3-1-2}`。
- **引用**：正文用 `[-@sec-3-1] 节`、`第 [-@sec-3] 章` 引用，渲染为裸数字（如 `3.1 节`、`第 3 章`）。
- **不编号**：仅 `参考文献` 带 `{.unnumbered}`；`本章总结`/`本章小结` 仍编号（如 ch04 的 `4.4 本章总结`）。
- **代码块内**：docstring/注释里的章节引用（如 `式(13.5)`、`第8章`）保留手动数字，不转 `@sec`（代码里交叉引用不生效）。

## 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `withBinaryFile: permission denied` | `--to` 标志位置不当（`quarto render --to html .`） | 改为 `quarto render . --to html`（目录在前、`--to` 在后） |
| 交叉引用无法解析（`Unable to resolve crossref @eq-…`） | 公式 `$$` 与 math 之间多出空行，或 `{#eq-…}` 漏写 `#` | 保证 `$$` 紧邻 math 无空行；ID 写作 `{#eq-…}` |
| PDF 中文乱码 | 缺少 ctex 或 pdf-engine 不对 | 确认 TinyTeX 装有 `ctex.sty`，`pdf-engine: lualatex` |
